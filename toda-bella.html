ERP Salón de Belleza "Toda Bella"

Sistema integral de gestión con Java Spring Boot y React

Este proyecto nació de la necesidad de digitalizar los procesos de un salón de belleza real. Es un sistema ERP (Enterprise Resource Planning) que centraliza la gestión de ventas, inventario, clientes, empleados y finanzas, permitiendo a los administradores tomar decisiones basadas en datos reales.

Stack Tecnológico

Java 21 Spring Boot Spring Data Spring Security PostgreSQL React + Vite TailwindCSS + Shadcn Docker Git

Módulos del Sistema

Seguridad & Login

Autenticación robusta utilizando Spring Security y JWT.

Dashboard

Gráficos interactivos para visualizar ingresos diarios, mensuales.

Punto de Venta

Interfaz ágil para registrar servicios y productos. Cálculo automático de comisiones para estilistas.

Clientes y Empleados

Gestión integral de clientes, administración del personal, y datos de contacto.

Inventario

Creación de items como productos o servicios y control de stock en tiempo real.

Finanzas

Visualización de los pagos a empleados historial y pagar.
